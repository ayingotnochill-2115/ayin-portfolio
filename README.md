# 🏎️ ANANYA CHOUHAN — Personal Portfolio & Creative Technology Hub

An ultra-modern, high-performance personal portfolio website built for **Ananya Chouhan** (Mechanical Design Engineer × Product Designer × Creative Technologist). 

The design fuses **Porsche Mission X** aesthetic architecture, **Mercedes-Benz Vision AVTR** dynamic lighting, **Apple-inspired UI hierarchy**, and **CAD Blueprint Canvas** overlay.

---

## ✨ Key Features & Design Philosophy

- **Cinematic Vision AVTR Lighting:** Volumetric interactive ambient radial glows reacting dynamically to mouse movements (`#bg-canvas`).
- **Precision CAD Blueprint Mesh:** Procedural canvas overlay mimicking mechanical engineering grid layouts.
- **GSAP & Lenis Smooth Scroll:** Fluid, inertia-driven scrolling experience for ultra-premium UX.
- **Dynamic Case Study Modal System:** Interactive popup modals presenting detailed engineering problems, methodologies, research, and measurable impact.
- **Glassmorphic Floating Navigation:** Frosted glass navbar (`backdrop-filter: blur(28px)`) featuring responsive navigation links.
- **Interactive Tech Stack Matrix:** Color-coded proficiency levels across Mechanical CAD, Visualization, and AI workflows.
- **Infinite Certification Marquee:** Seamless CSS-animated continuous carousel displaying verified credentials.
- **Custom Precision Cursor:** Dual-layer hardware precision cursor with real-time hover states.

---

## 🛠️ Tech Stack & Dependencies

* **HTML5 & CSS3:** Custom CSS variables, CSS grid/flexbox, advanced keyframe animations.
* **JavaScript (ES6+):** Dynamic DOM rendering, interactive canvas rendering, modal triggers.
* **GSAP 3:** High-performance animation sequences and ScrollTrigger integrations.
* **Lenis:** Next-gen smooth scrolling library by Studio Freight.
* **Google Fonts:**
  * `Plus Jakarta Sans` (Body & Titles)
  * `IBM Plex Mono` (Technical Callouts & Code Badges)
